# Four rabbit replacements — v03

This original-source packet rebuilds only the huge mutant rabbit boss and three Victorian rabbit enemies. Earlier six-base and twelve-expansion outputs are preserved. No other model is exported by this script.

The crouched boss has enlarged folded hindquarters, smaller forepaws, long rear feet, a split rabbit muzzle with separate incisors and whisker beds, crooked articulated ears, layered fur, dorsal crystals and eye-seal metalwork. The three clothed variants have different head treatment and accessories, bent animal legs, shaped lapels/cuffs, separate moving coat tails, original worn cloth patterns and a cracked porcelain mask with a small dark nose.

All four use the owner's approved Prismatic direction: readable dark anatomy, cyan/magenta/violet/emerald iridescence, original painted detail and restrained gold eye motifs. The atlas is embedded in textured GLB and copied to native Java/Bedrock resource sources. Software previews sample that actual atlas on articulated geometry with a fixed camera.

The generator creates four 2000×2000 four-view sheets and four genuine articulated 16-frame software-preview GIFs. These remain export targets until an actual hosted run completes. The validator inspects actual file bytes, UV/texture correspondence, bone topology, animation, bounds and decoded previews. Personal visual review and native acceptance remain separate.

No numeric registry allocation, world installation, live mob registration or gameplay readiness is claimed. Opt-in assembly is uninstalled source and requires the owning behavior/site adapter. A maximum of 32 bones is checked in genuine source tests.

Only files listed in PUBLIC_SOURCE_ALLOWLIST.json may be copied to a public branch. Private .nsp reference images, logs and resource receipts are excluded. The workflow template uses a free Ubuntu 24.04 hosted runner, pinned Python/Pillow dependencies and exact reviewed-main commit binding; no local render fallback, paid provider or unchanged-model rerun is included.
