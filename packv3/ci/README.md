Run in an isolated CI checkout with Java 21 and a Python virtualenv. Install requirements.txt inside that virtualenv, then run run_pack_engine.py. The runner downloads the Mojang 1.21.1 server by its official SHA1, generates a fresh baseline, copies it, then executes real unittest cases on that copy. Never upload runtime/server.properties or authentication files as artifacts. Safe artifacts: ACTUAL_PACK_ENGINE.json, COMMANDS_ACTUAL.json, unittest_actual.log, runtime/baseline.log, runtime/test.log.
